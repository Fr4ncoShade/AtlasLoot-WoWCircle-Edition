# AtlasLoot WoWCircle Edition (3.3.5)
This version includes custom items that are not present in the original addon and are available on WoWCircle.  
  
Main changes:  
* Added items from Naxxramas (Hard Mode)  
* Added items from ICC (Mythic)  
* Support for custom server content

⚠️**This addon is intended for use on WoWCircle only and may not function correctly on other servers.**
